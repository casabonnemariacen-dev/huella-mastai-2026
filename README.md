# Calculadora de Huella de Carbono – Mastai – Fiesta de la Cerveza del NEA Argentino, Corrientes 2026

Herramienta educativa de **IANES / UCP** para estimar la huella de carbono de la
**visita** a la Fiesta (Anfiteatro Mario del Tránsito Cocomarola, Av. Domingo
Sarmiento 2650, Corrientes).

> README en construcción: se completa en la etapa 3.

## Ejecutar localmente
```bash
npm install
npm test        # pruebas unitarias
npm run dev     # servidor de desarrollo
```

## Factores de emisión
Todos los números están en `src/data/factores.js`, con valor, unidad, fuente,
año y la marca `estimado`.
